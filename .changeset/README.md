# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos that need to version and publish multiple packages.
It uses [Changesets](https://github.com/changesets/changesets) to manage versions, and changelogs.

You should run `pnpm changeset` to add a changeset for any change that should be released. The changeset
file describes the change and which packages it affects. When a PR is merged to `main`, the publish
workflow applies the version bumps and publishes the affected packages to GitHub Packages.

## Useful commands

- `pnpm changeset` — add a new changeset
- `pnpm changeset version` — apply version bumps from pending changesets
- `pnpm changeset publish` — publish packages to the registry
